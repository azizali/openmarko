# Articles: how to

1. Open **Articles**. Each website has a board: Ideas, Drafts, Scheduled, Published.
2. Choose **Suggest ideas** to get topics for keywords you track but have no article for, biggest opportunities first.
3. Open an idea to have the assistant draft it in your brand voice. Edit as needed.
4. Schedule or publish it. Publishing needs WordPress connected for that website (Settings → Websites).

Published articles show the clicks they've earned from Google.
