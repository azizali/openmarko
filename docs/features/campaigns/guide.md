# Campaigns: how to

1. Open **Campaigns** and start a new one, or select people in **Contacts** and choose Text or Email.
2. Pick the channel and the audience. You'll see who gets it and who's skipped, and why (no consent, no number, opted out).
3. Write the message or start from the assistant's draft. Merge fields like first name and booking link fill in per person.
4. Fix anything the checks flag: text length, link shorteners, treatment names, brand rules.
5. Preview it as any recipient, then send now or schedule it.

After it's sent, see how many were delivered, opened, replied, booked and opted out.
