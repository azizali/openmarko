# Reviews: how to

## Reply to reviews

1. Open **Business Profile → Reviews**. Pick a location if you have several.
2. Each new review has a reply drafted in your brand voice. Replies never confirm that the reviewer is a customer or patient.
3. Edit the draft if you like, then post it.

Ask the assistant to "reply to all" to handle every waiting review at once.

## Let replies go out on their own

In **Settings → Autopilot**, set **Reply to 4–5★ reviews** to **On its own**. Replies to 1–3★ reviews always wait for a person.

## Ask customers for reviews

Use the **Review request** recipe in **Workflows** to text or email customers after a visit.

If you can draft but not post, your role is set up for someone else to approve replies.
