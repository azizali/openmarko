# Site health: how to

1. Open **Site health** to see your website's score, page speed (Core Web Vitals) and issues by severity.
2. Open an issue to see why it matters and which pages it affects.
3. Pick the pages to fix, check the before/after preview, and apply. Changes can be rolled back.

Fixes are applied through WordPress. If your site isn't on WordPress, the issue shows what to change by hand.

Choose **Re-crawl site** after making changes yourself.
