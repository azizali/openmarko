# Workflows: how to

## Start from a recipe

Open **Workflows** and pick a recipe: Speed to lead, Missed call text-back, Appointment reminders, Review request, 6-month recall, Reply YES to book, Birthday, and more. Adjust it and switch it on.

## Build your own

1. **When**: what starts it, such as a new contact, a tag added, a missed call, an appointment booked, or a date like 180 days after the last visit.
2. **Only if**: conditions on the person (tags, stage, where they came from, location, whether they can be texted or emailed).
3. **Steps**: texts, emails, waits, call tasks for the front desk, stage changes, tags, or starting another workflow. A step can run only if they haven't replied or booked.
4. **Stop when** they reply, book or opt out.
5. Switch it on.

Adding a tag in one workflow can start another, so workflows can hand people on. The sidebar shows what feeds into and out of each one.
