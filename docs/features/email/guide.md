# Email: how to

See **Set up email sending** in the integrations guide ([platform/integrations/guide.md](../../platform/integrations/guide.md#set-up-email-sending)).

In short: **Settings → Email & texting → Email setup**, pick a provider, add a sending domain, add the DNS records, and choose **Check now** until it's verified. Then set the from name, from address, reply-to and footer.

If you send to patients, use a provider that signs a BAA. Each option says whether it does.
