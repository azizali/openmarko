# Turning features on and off: how to

1. Open **Settings → Features**.
2. Each area (Local SEO, Social media, Ads, Contacts & messaging, Prospecting, Assistant) and each feature inside it has a switch. Each row says whether its account is connected and what changes elsewhere when it's off.
3. Switch it off. If other features rely on it, you'll see which ones first.

Turning something off hides its pages and its buttons elsewhere in the app. Nothing is deleted: switch it back on and everything returns as it was.

Inbox and Campaigns need Email or Texting on. Turning a whole area off turns off everything in it.
