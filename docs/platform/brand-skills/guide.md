# Brand voice and skills: how to

## Set your brand voice

**Settings → Brand voice** describes how your business sounds. The assistant uses it for everything it writes: review replies, posts, articles, emails and reports.

1. Check the one-sentence summary and adjust the tone sliders.
2. Add words to use and words never to use.
3. Add examples that do and don't sound like you.
4. Fill in **Business facts**: services, what makes you different, current offers and rules the assistant must always follow (for example, never confirming someone is a patient).
5. Use **Try it** to paste any text and see it rewritten in your voice.

## Manage skills

A skill tells the assistant how to write one kind of thing. **Settings → Skills** has Built-in, Public and Custom tabs.

- **Turn a skill off** and the assistant won't write that way.
- **Edit** a skill to change its instructions; edited built-in skills can be reset.
- **Locked** skills (review replies, community replies) carry privacy and platform rules and can only be turned on or off.
- **Browse public skills** to add one; you'll see the full file and whether the publisher is verified before adding it.
- **New skill** or **Upload .md** to write your own.

Each answer from the assistant says which skill it used.
